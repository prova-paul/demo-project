# /qa-gate

`.claude/docs/qa-checklist.md` উপর থেকে নিচ পর্যন্ত ধাপে ধাপে সম্পন্ন করুন। প্রতিটি আইটেমের জন্য: সরাসরি আসল code-এর
সাথে মিলিয়ে যাচাই করুন (grep/read করুন, কী তৈরি হয়েছিল তার স্মৃতি থেকে অনুমান করবেন না), pass/fail রিপোর্ট করুন,
এবং কোনো fail হলে, নীরবে ঠিক না করে থামুন এবং সেটি রিপোর্ট করুন — QA gate সমস্যা
সামনে আনে, চুপচাপ patch করে না।

শেষে একটি সারসংক্ষেপ দিন: কী pass করেছে, কী fail করেছে, এবং `main` deployment promotion-এর জন্য
মানুষের হাতে তুলে দেওয়ার উপযুক্ত কিনা। Promotion নিজে কখনোই agent দ্বারা করা হয় না।
